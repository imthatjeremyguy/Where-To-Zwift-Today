# Where to Zwift Today

A free static website that randomly picks a Zwift route from the worlds active that day.

- Hosted on GitHub Pages (static HTML/JS, no server, no database).
- A scheduled GitHub Action will fetch Zwift's world schedule and route data daily and commit them as JSON.
- Watopia is always active; two guest worlds rotate. Changeover is midnight US Eastern (4am UTC).

Status: coming soon.

## Data

`data/schedule.json` and `data/routes.json` are generated by `scripts/update_data.py` from Zwift's `MapSchedule_v2.xml` and `GameDictionary.xml`. The "Update Zwift data" GitHub Action runs it daily and commits only when something changed. To run it by hand: Actions tab, "Update Zwift data", "Run workflow".
